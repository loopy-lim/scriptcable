# @scriptcable/react-native

React Native adapter with three integration tiers:

```ts
// 1. Tests / Storybook — no native module needed
import { createMockBridge, createReactNativeEngine } from '@scriptcable/react-native';
const engine = createReactNativeEngine(
  createMockBridge({ add: (a, b) => Number(a) + Number(b) }),
);

// 2. Device — TurboModule bridge (JSON protocol: call(name, argsJson) -> Promise<string>)
import { createTurboModuleBridge } from '@scriptcable/react-native';
import NativeCable from '../.scriptcable/generated/NativeCable'; // generated spec
const engine = createReactNativeEngine(createTurboModuleBridge(NativeCable));
await engine.invoke('add', [20, 22]); // 42

// 3. Typed client (generated by `scriptcable build --hosts react-native`)
import { createReactNativeClient } from '../.scriptcable/generated';
const client = createReactNativeClient(createTurboModuleBridge(NativeCable));
client.add(20, 22); // fully typed
```

## Generated artifacts (`scriptcable build --hosts react-native`)

| File | Purpose |
|------|---------|
| `react-native.ts` | Typed client factory |
| `NativeCable.ts` | TurboModule spec — single `call(exportName, argsJson)` entry + optional typed shortcuts |
| `cable.json` | RN CLI codegen config (cpp) so the native side stays in sync |

## Linking the native library

- iOS: drop `.scriptcable/lib{name}.a` (or an XCFramework from `SCRIPTC_TARGET=aarch64-apple-ios`) into your module's Xcode project.
- Android: add the archive to your module's CMake (`add_library(name STATIC IMPORTED)` + `target_link_libraries`).
- Implement `call(exportName, argsJson)` dispatching to the C ABI (`{prefix}{export}` symbols).

The example app (`examples/react-native-app`) shows the `useCable` hook pattern with automatic mock fallback — the same code runs in tests, Storybook, and on device.

WASM-on-RN is an opt-in extra (needs a WASI runtime); native linking stays the default.
